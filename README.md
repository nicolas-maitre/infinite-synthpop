# Infinite Synthpop

An endless generative 1987–89 synth-pop machine for the browser, in the style of New Order's
"True Faith" and Peter Schilling's "The Different Story (World of Lust and Crime)". Every song is
composed from a seed. When it ends, the next one starts.

The musical rules come from an analysis of both songs, measured from the recordings and
cross-checked against published sources: see [docs/analysis.md](docs/analysis.md). The design is
in [docs/plans/generator-design.md](docs/plans/generator-design.md).

## Quick start

```bash
pnpm install
pnpm fetch-samples   # one-time: downloads the drum-machine samples into public/samples/
pnpm dev             # http://localhost:5173
```

Press **Play**. Without the samples, the app falls back to synthesized drums, so it still works.

## Controls

- **Play / Stop, New song, Skip section.** Keyboard: Space, N, S. Click a block on the timeline to
  jump to that section.
- **⟲ Loop** repeats the current section. **Autoplay** starts the music when the page loads. If
  the browser blocks audio until you interact with the page, the first click or key press anywhere
  starts it. To allow real autoplay:
  - **Chrome:** install the app (the install button in the address bar). Chrome lets installed
    web apps start audio on their own.
  - **Firefox:** `about:preferences#privacy` → Permissions → Autoplay → Settings…, then add
    `http://localhost:5179` with "Allow Audio and Video".
  - **Safari:** Settings → Websites → Auto-Play → "Allow All Auto-Play" for the site.
- **✚ Create…** is a new-song wizard. Pick the style, key, tempo, drum machine and bass figure.
  Choose the verse and chorus chords from the measured presets (closest to the style first), or
  set them bar by bar. Then set the length (short, standard, long) and the ending (lift to the
  major IV, or chorus to fade), and generate. The result is a creation, so you can keep editing it.
- **Piano roll:** the whole current section under the timeline, one lane per instrument, with
  each bar's chords and a playhead. Click a bar to jump there.
- **✎ Creator:** edit the playing song in place:
  - Click a timeline block to select a section, drag blocks to reorder, and use **+** at the end
    to add one.
  - The chords display turns into one picker per bar, with an optional second chord for the
    bar's second half, and +/− to change the pattern length.
  - Under the piano roll you set the selected section's name, type, length and key, its drums and
    instruments, the lead melody, and a fill at its end.
  - **Melody:** each section's lead plays the generated verse or chorus melody, or one of your
    own (✎). Your own melodies come from four places, and editing one changes it in every
    section that shares it:
    - **Edit in the piano roll:** the Lead lane becomes a note grid snapped to the key's scale
      (hold Shift for any semitone). Click to add a note, drag a note to move it or its right edge
      to change its length, and double- or right-click to delete it.
    - **New melody:** writes a fresh melody over the section's chords, with a range (low, mid,
      high) and a density (sparse, normal, busy).
    - **● Record:** the section loops with its lead silenced while you play the melody in. Use the
      computer keys A W S E D F T G Y H U J K (Z / X to change octave) or a MIDI keyboard. Notes
      snap to 16ths, and you hear them as you play.
    - **Import MIDI…:** take a track and a range of bars from a MIDI file.

    Melodies are stored relative to the key they were written in, so changing the key transposes
    them by the nearest interval.

  - The song's title is edited in place, at the top. The **Song** line holds key, tempo, drum
    machine, bass figure and feel.
  - Edits play from the next bar and are saved in the browser. The URL carries the song
    (`#song=…`), so a link replays it. A creation loops until you pick another song.
- **Export:** **MIDI** (every instrument on its own track, drums on channel 10, sections as
  markers) or the whole song's audio with the current mixer as **MP3** (256 kbps, encoded in the
  page) or **WAV**. Audio exports stop playback while they render.
- **Originals:** play _True Faith_ or _The Different Story_ through the same engine, at their
  measured form, chords, key, tempo, drum machine and bass figure. The melodies stay generated.
  Links: `#ref=true-faith`, `#ref=different-story`. Generated songs follow when one ends.
- **Follow MIDI…:** pick a MIDI file to drive the current original. Each mixer row then gets a
  **MIDI** switch (generated ↔ MIDI) and a select for which of the file's tracks it follows.
  Tracks are matched by name ("Sequence Bass" → Seq bass, "Lead" → Lead, both drum tracks →
  Drums, …), and you can correct any match. "None" silences an instrument. Each part is scaled to
  the generated part's usual level, since transcriptions often have flat velocities. The file is
  read in the page and never stored. It is mapped by bar and 16th, so its tempo doesn't matter,
  but its bars must line up with the original's layout (a True Faith transcription with 4 bars of
  drums before the bass does).
- **Seed:** every song is reproducible. The URL carries `#seed=…`, so a link replays the same song.
- **Style:** a slider from _True Faith_ (Dorian IV choruses, minor v, a brighter, lower bass,
  the high 16th sequencer, modulating outro) to _The Different Story_ (minor iv choruses, major
  V, Dorian turnaround, chorus fade). Both share the sequenced bass figure.
- **Tempo:** auto (115–120 BPM; both originals measure 117.45) or fixed.
- **Key:** auto or a fixed minor key.
- **Drum machine:** E-mu SP-12, LinnDrum, Oberheim DMX or synthesized.
- **Mixer:** per-track volume, mute and solo, plus a master fader.

## How it's built

All the music logic is pure and deterministic, with no audio involved, which is what makes it
unit-tested. Tone.js only plays the result.

```
src/rng.ts           seeded PRNG
src/theory.ts        keys, Roman-numeral chords, scales (incl. Dorian / harmonic-minor colour), voicing
src/progressions.ts  progression bank measured from the recordings + style-weighted substitutions
src/references.ts    the two originals: measured form, chords, key, tempo, kit, bass figure
src/midi.ts          minimal MIDI file reader for user-supplied tracks
src/composer.ts      seed → Song: form, progressions, riff / melodic-bass / arp motifs, lead melodies
src/arranger.ts      (song, bar) → every note and drum hit in that bar
src/drums.ts         sample kits with synthesized fallback
src/instruments.ts   synth voices, gated reverb, buses, mixer
src/engine.ts        bar-by-bar scheduler that chains songs forever
src/render.ts        offline render (exports, and dev measurement)
src/spec.ts          creator mode's song format: song ↔ spec, link encoding
src/creator.ts       creator mode UI (timeline, chords, section panel, melody tools)
src/melodies.ts      custom melodies: write, import, share between sections
src/recorder.ts      record a melody from the computer keyboard or a MIDI keyboard
src/wizard.ts        the new-song wizard
src/pianoroll.ts     the current section's piano roll
src/export.ts        MIDI, WAV and MP3 export
src/main.ts          UI
```

## Measuring against the reference recordings

Put the reference tracks in `inspiration/` (git-ignored). Then:

```bash
python3 -m venv .venv && .venv/bin/pip install -r scripts/requirements-analysis.txt
.venv/bin/python -I scripts/analyze_reference.py inspiration/*.mp3 --out docs/reference-data.json
```

To measure the generator itself, run `await renderToDisk({ seed: 42, style: 0.5 })` in the dev
page's console. It renders the song offline into `renders/`. For stems, pass a bar count and the
tracks to solo: `renderToDisk({ seed: 42, style: 0.5 }, 64, ["bass"])`. Then compare the mixes:

```bash
.venv/bin/python -I scripts/compare_mix.py inspiration/*.mp3 renders/*.wav
```

You can also run `analyze_reference.py` on a render to check its tempo, chords and form.

To transcribe a part of a recording (or of a render's stems), separate it with Demucs and run
`scripts/transcribe_bass.py` on the stem folder. Its docstring has the commands. That is how the
bass figure in `docs/analysis.md` §3 was measured.

## Sample licensing

The drum samples come from
[geikha/tidal-drum-machines](https://github.com/geikha/tidal-drum-machines), pinned to a commit in
`scripts/fetch-samples.mjs`. That repository states no license, so the samples are git-ignored and

The MP3 encoder is [@breezystack/lamejs](https://www.npmjs.com/package/@breezystack/lamejs)
(a JavaScript port of LAME, LGPL-3.0), installed as a dependency and bundled with the app.
